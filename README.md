# イディオム500

イディオム問題500問の4択演習アプリです。サーバー不要の静的ファイルだけで動きます。

## 使い方
- 範囲別(No.1–20, 21–40 …)、ランダム20問、間違えた問題のみ、から選んで演習します。
- 不正解の問題は自動でストックされます。正解でも自信がなければ「☆ 自信がない：ストックに追加」で手動ストックできます。
- 途中で「中断してトップへ」を押しても、それまでのストックは残ります。
- ストックは、ブラウザの localStorage に保存されます（端末・ブラウザごと）。
- 「間違えた問題のみ」で正解したら、「ストックから外す」で一覧から消せます。
- キー操作：数字キーで選択肢を選び、Enter で次の問題へ進みます。

## GitHub Pages で公開する
1. このフォルダのファイルをすべてリポジトリのルートにアップロードします。
2. Settings → Pages → Branch を `main` / `(root)` にして Save します。
3. 表示された URL を開きます。

## ファイル
- `index.html` … アプリ本体
- `questions.js` … 問題データ（アプリが読み込む）
- `idiom_500.csv` … 元データ
- `make_questions_js.py` … CSVを編集したあと `python3 make_questions_js.py` で questions.js を作り直す
